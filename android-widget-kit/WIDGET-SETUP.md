# Виджет на главный экран Android — установка под ключ

Показывает число дней до конца молодости прямо на рабочем столе телефона —
не нужно открывать приложение. Обновляется автоматически, каждый день заново.

**Важно понимать сразу:** Android физически не позволяет виджетам тикать
секунда-в-секунду — это ограничение системы для всех приложений (даже у
банковских и погодных виджетов), минимальный плановый период обновления — 30
минут. Так как число дней меняется только раз в сутки, этого достаточно.
Дополнительно код ставит точный будильник на полночь, чтобы число менялось
именно в момент смены дня, а не когда системе будет удобно.

## Что уже сделано за вас (в веб-части)

- `package.json` — добавлена зависимость `@capacitor/preferences`
- `capacitor.config.json` — настроена группа хранения `dkmo_widget_prefs`
- `src/widgetSync.js` — при каждом изменении даты рождения / возраста в
  Настройках эти два поля дублируются в нативное хранилище
- `src/App.jsx` — вызывает `syncWidgetData` автоматически

Это уже собирается и работает как обычно — само по себе оно ничего не ломает,
даже если вы не станете добавлять сам виджет.

## Шаг 1 — обычная сборка

```bash
npm install
npm run build
npx cap add android      # если ещё не делали
npx cap sync android
```

## Шаг 2 — скопировать файлы виджета

Все файлы уже лежат в папке `android-widget-kit/` в корне проекта, готовые
для копирования. Скопируйте их **точно по этим путям** внутри `android/`:

| Откуда (`android-widget-kit/...`)         | Куда (`android/app/src/main/...`)                        |
|---------------------------------------------|-----------------------------------------------------------|
| `DkmoWidgetProvider.kt`                     | `java/com/dkmo/app/DkmoWidgetProvider.kt`                 |
| `res/layout/dkmo_widget.xml`                | `res/layout/dkmo_widget.xml`                               |
| `res/drawable/dkmo_widget_background.xml`   | `res/drawable/dkmo_widget_background.xml`                  |
| `res/xml/dkmo_widget_info.xml`              | `res/xml/dkmo_widget_info.xml`                              |
| `res/values/dkmo_widget_strings.xml`        | `res/values/dkmo_widget_strings.xml`                        |

Команда одной строкой (запускать из корня проекта):

```bash
mkdir -p android/app/src/main/java/com/dkmo/app
cp android-widget-kit/DkmoWidgetProvider.kt android/app/src/main/java/com/dkmo/app/
cp android-widget-kit/res/layout/dkmo_widget.xml android/app/src/main/res/layout/
cp android-widget-kit/res/drawable/dkmo_widget_background.xml android/app/src/main/res/drawable/
cp android-widget-kit/res/xml/dkmo_widget_info.xml android/app/src/main/res/xml/
cp android-widget-kit/res/values/dkmo_widget_strings.xml android/app/src/main/res/values/
```

(Папки `res/xml/` и `res/drawable/` могут не существовать в свежем проекте —
`cp` с `mkdir -p` выше создаст недостающие; если каких-то команд не хватает,
создайте папки вручную перед копированием.)

## Шаг 3 — добавить блок в AndroidManifest.xml

Откройте `android/app/src/main/AndroidManifest.xml`. Внутри тега
`<application ...> ... </application>` вставьте блок `<receiver>` из файла
`android-widget-kit/AndroidManifest.snippet.xml` (там же — закомментированная
строка про необязательное разрешение точных будильников, см. пояснение в
самом файле).

Больше в манифесте ничего менять не нужно.

## Шаг 4 — собрать и добавить виджет на экран

1. В Android Studio: **Build → Rebuild Project**, затем ▶ Run на устройство/эмулятор
2. Откройте само приложение хотя бы раз и пройдите онбординг (укажите дату
   рождения) — это создаст запись в `dkmo_widget_prefs`, которую прочитает виджет
3. На главном экране телефона: долгое нажатие на пустом месте → **Виджеты**
   → найдите «ДКМО — дни до конца молодости» → перетащите на экран

## Если что-то пошло не так

- **Виджет показывает «—»** — значит нативное хранилище ещё пустое. Откройте
  приложение, пройдите/повторите онбординг, подождите пару секунд, вернитесь
  на рабочий стол.
- **Число не совпадает с приложением день-в-день** — маловероятно (формула
  честно скопирована 1:1 из `src/App.jsx`), но если увидите расхождение —
  дайте знать.
- **Число не обновляется вовремя в полночь** — на некоторых устройствах
  (особенно Xiaomi/Huawei/Samsung с агрессивной экономией батареи) система
  может убивать точные будильники сторонних приложений. Помогает: настройки
  → приложения → ДКМО → отключить ограничения по батарее / разрешить работу
  в фоне. Даже без этого виджет обновится в течение получаса благодаря
  плановому системному циклу — просто не секунда в секунду.

## Если пересоздаёте папку `android/` с нуля

Папка `android/` не хранится в git (см. `.gitignore`) и создаётся заново
командой `npx cap add android`. Если вы когда-нибудь удалите её и создадите
заново — `npx cap sync android` **не** восстановит файлы виджета (он трогает
только веб-ассеты и список нативных плагинов). В этом случае просто повторите
шаги 2 и 3 из этой инструкции — файлы для копирования остаются в
`android-widget-kit/` в корне проекта, они никуда не денутся.

Если хотите, чтобы это не повторялось — уберите `android/` из `.gitignore`
и закоммитьте папку целиком в git (так же, как описано в README для
настройки подписи релиза) — тогда все нативные правки, включая виджет,
сохранятся между пересборками.
